# CLI Weather App ⛅

**INTERNID:** CITS8323

A lightweight, interactive Command-Line Interface (CLI) Weather App built with Python. It fetches real-time weather data from the OpenWeatherMap API based on user input and elegantly displays current conditions like temperature, humidity, and wind speed right in the terminal.

## Features

* **Real-Time Data:** Fetches up-to-date weather conditions dynamically via API.
* **Beautiful CLI Output:** Uses standard formatting and emojis to make terminal output visually appealing and easy to read.
* **Error Handling:** Gracefully handles invalid city names, missing API keys, and internet connection issues without crashing.
* **Continuous Loop:** Allows users to check multiple cities in a single session without having to restart the script.
